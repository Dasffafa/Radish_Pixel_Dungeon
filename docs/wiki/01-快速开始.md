# 01 快速开始

## 这是什么

`Radish_Pixel_Dungeon`（萝卜地牢）是 Shattered Pixel Dungeon 的深度改造分支：在保留上游框架的前提下，加了大量自定义职业、Boss、NPC、物品与 UI 改造。

- 上游参考（只读，已 `git clone` 到本地 `_upstream/spd`、`_upstream/darkest`）
- 当前版本：`0.8.4-base2.4.2`（`appVersionCode = 2608060`）
- 主语言：Java；构建：Gradle 8.11.1 + Android Gradle Plugin

## 五分钟跑起来

```bash
# 1. 只验证 Java 编译（最快反馈，通常 40~60s）
./gradlew :core:compileJava --console=plain

# 2. 打 Android 调试包
./gradlew :android:assembleDebug --console=plain
# 产物：android/build/outputs/apk/debug/android-debug.apk

# 3. 桌面版（本机 JDK 23，LWJGL 窗口）
./gradlew :desktop:debug
```

> 退出码 1 但输出 `BUILD SUCCESSFUL` 属正常（javac 的 stderr 警告）。

## 目录速览

| 路径 | 内容 |
|---|---|
| `core/src/main/java/` | 几乎全部游戏逻辑（`com.shatteredpixel.shatteredpixeldungeon.*`） |
| `core/src/main/assets/` | 贴图、音频、`messages/*.properties` 文本 |
| `SPD-classes/src/main/java/` | 从上游拆出的公共层（noosa 引擎、通用工具） |
| `android/`、`desktop/` | 两个平台壳 |
| `docs/` | 文档（本 Wiki 在 `docs/wiki/`） |
| `_upstream/` | 上游参考仓库（只读、已 gitignore） |
