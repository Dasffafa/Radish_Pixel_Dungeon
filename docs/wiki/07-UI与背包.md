# 07 UI 与背包

## 三层控件

| 层 | 位置 | 例子 |
|---|---|---|
| Scene | `scenes/` | `GameScene`、`TitleScene` |
| Window | `windows/` | `WndBag`、`WndQuest`、`WndOptions` |
| UI 组件 | `ui/` | `RedButton`、`RenderedTextBlock`、`ScrollPane` |

自绘组件一律是普通 `Component`，交给宿主 Scene；**不要自己 new Camera**。

## 背包（`windows/WndBag.java`）

- 布局：5 列 × 固定可见行（超过就滚），格子 `SLOT_WIDTH_P/SLOT_HEIGHT_P = 28`，`SLOT_MARGIN = 1`
- 容量：`items/bags/Bag.java` 的 `capacity()` = 53（含扩展后的 +18）
- 行数：`nRows = ceil((已装格数)/(列数))`，可见行取 `maxVisibleRows`（按 `uiCamera.height` 算），窗口高度超出就交给 `ScrollPane`
- 装备行固定 6 格：`weapon / armor / secondaryArmor / artifact / misc / ring`
- 滚动：内容装不下时用 `ui/ScrollPane`，**滚动条 thumb 是覆盖式的**（`thumb.x = width - thumb.width() - 1`）

### 两个已踩过的坑

1. `ScrollPane` 的 `controller` 是 `ScrollArea`，它必须铺满可视区（`setRect(0,0,width,height)`），否则拖动收不到事件 → 表现为「列表拖不动」。
2. 格子的 `PointerArea` 默认 `BLOCK_WHEN_ACTIVE`，会吞掉 DOWN → 拖动失效。要在匿名 `InventorySlot` 的实例初始化块里改成 `NEVER_BLOCK`。

## 常驻侧栏

`ui/InventoryPane.java` 是桌面/手机右侧的常驻背包面板，列数按面板宽度算：
`cols = (availW + 1) / (SLOT_WIDTH + 1)`，可用宽度 `width - 8`。

## 布局尺寸自检

- 竖屏 1080×1920 / density 320、横屏、以及放大到 6 倍时，窗口都要完整在屏内
- 窗口高度 = `标题 + 可见行 × (格高+间距) + 底部标签`，别忘了 `tabHeight()` 与 `chrome` 边距
