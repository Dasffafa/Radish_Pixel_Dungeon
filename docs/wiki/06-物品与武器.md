# 06 物品与武器

## 物品体系速览

```
Item
 ├─ Weapon ─── MeleeWeapon / MissileWeapon / 法杖(Wand)
 ├─ Armor ──── 普通护甲 / 次要护甲(SecondaryArmor，本项目新增槽位)
 ├─ Potion / Scroll / Stone / Food / Wand …
 └─ Artifact（神器，独立充能）
```

## 新增一件武器/物品

1. `items/weapon/melee/Xxx.java`：`image`、`tier`、`damage`、`DLY`、`ACC`、`stats_desc`
2. 贴图：**优先用同名单图** `assets/sprites/items/xxx.png`（本项目 `ItemSpriteSheet.ATLAS` 是运行时图集，不必再往 `items.png` 里塞格子）
3. 生成池：`Generator` 的 `classes` 与 `probs` 等长追加
4. 文本：`items.weapon.melee.xxx.name / desc / stats_desc`（中英都写，英文缺会 NTF）
5. 公告：`RA_v0_8_X_Changes.java` 加条目

## 次要护甲（本项目特有）

- 基类 `items/armor/SecondaryArmor.java`，12 件子类在 `items/armor/secondary/`
- 装备槽在 `Belongings.secondaryArmor`，界面显示在背包第 1 行的第 3 格
- **无法附魔、无法打磨**（`isUpgradable() = false`），但吃普通护甲的生成池与售价
- 描述模板：`items.armor.secondaryarmor.base_desc`，效果数值走 `effectArgs()` 动态注入
- 装备时记得 `detach(belongings.backpack)`，否则物品会同时出现在背包和装备栏

## 伤害系统

本项目把伤害重构成了 `damage/DamageInfo` + `DamageType`：
`new DamageInfo(base, DamageType.PHYSICAL, attacker, sourceItem, source)`，
`Char.damage(DamageInfo)` 结算；伤害修正用 `info.addFinalMultModifier(...)`。

> 旧写法 `mob.damage(int, Object)` 仍在但已不是主路径，新代码请用 `DamageInfo`。
