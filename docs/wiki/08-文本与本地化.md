# 08 文本与本地化

## 文件

`core/src/main/assets/messages/`

```
items.properties / items_zh.properties
actors.properties / actors_zh.properties
windows.properties / windows_zh.properties
levels.properties / levels_zh.properties
journal / misc / scenes / ui …
```

格式：`键=值`，一行一条。

## 键名规则（最容易错）

`Messages.get(Class c, String k)` 拼键：

```
c.getName().replace("com.shatteredpixel.shatteredpixeldungeon.", "") + "." + k
```

即 **包路径 + 类名全小写 + `." + 键`**：

- `actors.mobs.warden.name`
- `items.weapon.melee.whitekinggodsword.desc`
- 内部类用 `$`：`actors.hero.talent$iaistance.name`
- 物品组的键会带 `items.` 前缀，怪物/NPC 在 `actors.`，窗口在 `windows.`

**写错键名 → 游戏里显示键名或 `!!!NO TEXT FOUND!!!`**，不要靠猜，去同类条目里抄。

## 三个会翻车的写法

| 写法 | 结果 |
|---|---|
| 文字里写裸 `%` | 该文本带参时 `String.format` 抛异常 → 整串回退原文 |
| 用 `/n` 想换行 | 无效，必须 `\n`（反斜杠 n） |
| UTF-8 中文文件被脚本按 GBK 写 | 键名乱码、查不到 |

## 行内标记

- `_文字_`：强调色
- `**文字**`：加粗色
- 数字/数值通常包成 `_%d_`，单位不要在强调内部（`_3_ 点护盾`，不是 `_3 点护盾_`）

## 中英同步

本仓库大量英文键是历史欠账。**新加的键必须中英都写**，否则英文界面会 NTF。
可以用脚本对比：

```bash
# 列出 zh 有、en 没有的键（示例）
python - <<'PY'
import re,io
zh=io.open('core/src/main/assets/messages/items/items_zh.properties',encoding='utf-8').read()
en=io.open('core/src/main/assets/messages/items/items.properties',encoding='utf-8').read()
zhk={l.split('=')[0] for l in zh.splitlines() if '=' in l and not l.startswith('#')}
enk={l.split('=')[0] for l in en.splitlines() if '=' in l and not l.startswith('#')}
print(len(zhk-enk), 'missing in en')
PY
```
