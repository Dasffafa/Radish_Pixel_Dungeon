# 03 构建与打包

## 常用命令

```bash
./gradlew :core:compileJava      --console=plain   # 只编译 Java（最快，40~60s）
./gradlew :android:assembleDebug --console=plain   # 打调试 APK（约 1~3 分钟）
./gradlew :desktop:debug                           # 跑桌面版窗口
```

- Java 23（系统 PATH 里的 `java`），Gradle wrapper 自带（8.11.1）。
- `local.properties` 的 `sdk.dir` 指向本机 Android SDK。
- 退出码 1 但打印 `BUILD SUCCESSFUL` = 正常（javac 警告）。

## 版本号

根 `build.gradle`：

```groovy
ext.appVersionCode = 2608060          // 约定：900 + minor*10 + patch 的变体
ext.appVersionName = '0.8.4-base2.4.2' // debug 包自动加 -INDEV 后缀
```

打包后可在 `android/build/outputs/apk/debug/output-metadata.json` 核对。

## 产物投递（本项目约定）

打完包**必须**：

1. 删掉桌面 `ai` 文件夹里旧的 `萝卜地牢_*.apk`；
2. 把新包复制成 `萝卜地牢_<appVersionName>_<yyyyMMdd-HHmm>.apk`；
3. 仓库里的标准产物保留，回复里给出桌面路径。

```bash
rm -f "C:/Users/<you>/Desktop/ai/"*.apk
cp android/build/outputs/apk/debug/android-debug.apk \
   "C:/Users/<you>/Desktop/ai/萝卜地牢_0.8.4-base2.4.2-INDEV_$(date +%Y%m%d-%H%M).apk"
```

## 本地测试包：Firebase 必须临时移除

没有有效 `google-services.json` 时，启动会崩在 `FirebaseInitProvider.onCreate`。本地打测试包需改五处，**打完立刻 `git checkout --` 还原，绝不提交**：

1. 根 `build.gradle`：注释 `classpath 'com.android.tools:r8:…'`
2. `android/build.gradle`：注释 `com.google.gms.google-services`、`com.google.firebase.crashlytics` 两个插件与两处 `firebaseCrashlytics { … }`
3. `android/src/main/AndroidManifest.xml`：`xmlns:tools` + `tools:node="remove"` 移除 `FirebaseInitProvider` 与 `CrashlyticsInitProvider`
4. `AndroidLauncher.java`：`FirebaseApp.initializeApp(this)` 包 try/catch
5. （可选）`gradle/runtime-atlas.gradle` 的 missing-png 校验临时改 `println`
