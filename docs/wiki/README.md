## 三条铁律（先记住，比重读文档快）

1. **新功能 = 新分支**：`feat/<短名>` / `fix/<短名>` / `docs/<短名>`，不许在已有功能分支上堆下一个功能。
2. **生物相关改动必读原文**：`docs/萝卜地牢开发文档/PD-生物开发原则.md`（第一优先级，冲突时以它为准）。
3. **改完要真跑**：至少 `:core:compileJava` 通过，涉及 UI/贴图要去模拟器或真机看一眼，不要只读代码下结论。

## 目录约定

```
docs/wiki/                 ← 本 Wiki（入口 + 分主题页）
docs/萝卜地牢开发文档/       ← 深度专题（架构、伤害系统、着色器、皮肤…）
docs/萝卜地牢进度文档/       ← 待办 / bugs / 更新日志 / 重构计划
AGENTS.md                  ← 常驻硬规则（本地文件，不入库）
```

- 本 Wiki 只做**指路 + 最短可用的做法**，细节一律链到专题文档或源码行号。
- 新增页面请同时更新本文件和 `INDEX.md`（`python tools/wiki_build_index.py` 可重新生成索引）。
