# 自走棋（Auto Battler）设计文档

> 对应挑战：`Challenges.AUTO_BATTLER`（`1<<15`）
> 入口：主菜单选挑战 → 开始游戏 → 进入 `ChessBoardLevel`（15×17 棋盘）
> 核心代码包：`com.shatteredpixel.shatteredpixeldungeon.challenges.autochess`

---

## 1. 一局的流程

```
标题 → 勾选「自走棋」挑战 → 开局
  └─ ChessBoardLevel 建图（15×17）
     ├─ 顶部：玩家观战台（封闭包间）+ 玩家备战席 9 格
     ├─ 中间：战场（左半 x1..6 我方，右半 x9..13 敌方，中线 x=7）
     └─ 底部：对手备战席 9 格 + 对手观战台

第 N 回合（备战）
  ├─ 商店 5 格（按等级概率抽，共享池）
  ├─ 买棋子 → 进备战席；拖到战场 = 上阵
  ├─ 买经验 / 刷新 / 锁牌 / 拖装备到棋子
  └─ 点「开战」

第 N 回合（战斗）
  ├─ 双方阵容铺到战场，英雄在包间观战
  ├─ 每 0.16 秒推进一回合（Dungeon.hero.spendAndNext）
  └─ 一方全灭 → 结算

结算
  ├─ 胜：对手掉 阶段基础 + 我存活数 点血；掉一件装备
  ├─ 负：自己掉 阶段基础 + 敌方存活数 点血；掉一件装备
  ├─ AI 之间按配对互相结算（战力 + 随机）
  └─ 进入下一回合（金币/经验结算，所有 AI 变强）
```

胜利条件：**其余 5 个 AI 全部血量归零**；失败条件：自己血量归零。

## 2. 经济

| 项目 | 数值 | 说明 |
|---|---|---|
| 初始金币 | 8 | `START_GOLD` |
| 初始生命 | 100 | `START_LIFE`，玩家和 AI 相同 |
| 基础收入 | 5 / 回合 | `BASE_INCOME` |
| 利息 | 每 10 金 +1，上限 +5 | 打完一回合结算 |
| 连胜/连败 | 2 连 → +1，3+ 连 → +2 | 补偿连败玩家 |
| 刷新 | 2 金 | `REFRESH_COST` |
| 买经验 | 4 金换 4 点 | `XP_COST` / `XP_PER_BUY` |
| 每回合白给经验 | 2 点 | `XP_PER_ROUND` |

### 等级与上阵位

- 开局 **1 级**，**上阵位 = 等级 + 2**（1 级 3 个，10 级 12 个）
- 经验表：`1→2: 2, 2→3: 2, 3→4: 6, 4→5: 10, 5→6: 20, 6→7: 36, 7→8: 48, 8→9: 76, 9→10: 84`
- 最高 10 级，超过不再升级

### 伤害公式

```
战败扣血 = 阶段基础 + 场上存活敌人数
阶段基础 = min(8, 2 + 回合数 / 5)
```

## 3. 棋子池与商店

### 共享池（`AutochessSharedPool`）

- 每张牌固定份数：1 费 22、2 费 18、3 费 15、4 费 12、5 费 9
- 玩家和 AI 从**同一个池子**抽牌，买走扣份、卖掉回池
- 抽空了商店就不会再出这张牌

### 商店概率（`AutochessPool.oddsForLevel`）

| 等级 | 1 费 | 2 费 | 3 费 | 4 费 | 5 费 |
|---|---|---|---|---|---|
| 3 | 65% | 25% | 10% | 0 | 0 |
| 4 | 50% | 35% | 15% | 0 | 0 |
| 5 | 40% | 30% | 25% | 5% | 0 |
| 6 | 30% | 35% | 25% | 10% | 0 |
| 7 | 20% | 30% | 30% | 15% | 5% |
| 8 | 15% | 25% | 30% | 20% | 10% |
| 9 | 10% | 20% | 25% | 25% | 20% |

### 商店 UI

- 5 张卡，按费用配色（1 灰 / 2 绿 / 3 蓝 / 4 紫 / 5 橙）
- 每张卡右上角 `i` → 棋子详情
- 底部：装备背包（图标 + 拖拽）、连胜栏、开战按钮
- 顶栏：买经验、刷新、锁定商店、对战大厅、本轮对手

### 星级

- 三只同名同星自动合成，升 1 星（最高 3 星）
- 2 星：生命/攻击 ×1.8，技能效果 ×1.6
- 3 星：生命/攻击 ×3，技能效果 ×2.2，持续类技能时长再拉长 50%（麻痹 +1 回合）
- 升星时有特效：闪光 + 星光粒子 + 升级音效 + ★★/★★★ 飘字

### 头顶标记

- 我方：蓝色小箭头
- 双方：金色星星图标（1~3 个）表示星级

## 5. 羁绊（12 系 = 6 种族 + 6 职业）

每只棋子固定 2 个羁绊：**一个种族 + 一个职业**。效果按场上同羁绊人数分档。

### 种族

| 羁绊 | 效果 | 档位 |
|---|---|---|
| 兽群 | 围攻：每个相邻敌人 +10%/档（最多 3 个） | 3/5 |
| 虫群 | 剧毒：攻击使目标中毒 | 3/5 |
| 亡灵 | 吸血：每回合回复 2% 最大生命/档 | 2/4 |
| 构装 | 装甲：每回合获得护盾，最多叠到 30% 生命 | 3/5 |
| 恶魔 | 斩杀：目标生命 <40% 时伤害 +50%/档 | 2/4 |
| 人形 | 阵型：每个相邻友军 +8%/档（最多 3 个） | 3/5 |

### 职业

| 羁绊 | 效果 | 档位 |
|---|---|---|
| 坦克 | 护盾：开战获得 20%/档 最大生命护盾，每回合补盾 | 2/4 |
| 刺客 | 突袭：对满血目标伤害成倍（1 档 ×2、2 档 ×3） | 3/5 |
| 射手 | 精准：距离 ≥3 时 +25%/档 | 2/3 |
| 战士 | 狂暴：生命越低伤害越高，最多 +15%/档 | 3/5 |
| 法师 | 灼烧：攻击点燃目标 | 2/4 |
| 辅助 | 庇护：治疗最残友军并给护盾 | 2/3 |

### 羁绊 UI

- 棋盘左侧**羁绊栏**：按档位排序，显示「羁绊 人数/下一档」，颜色区分档位
- 点羁绊 → `WndAutochessTraitList`：羁绊效果说明 + 该羁绊所有棋子（点棋子看详情）
- 底部单独一行：连胜/连败 + 上回合收入

## 6. 技能（47 个专属）

每只棋子一个专属技能，**攒满充能自动释放**：

- 充能：每回合 +10，被攻击 +4；法杖类装备可加快
- 充能需求 50~110，技能越强需求越高
- 技能类型：单体爆发、范围溅射、治疗、护盾、中毒、点燃、麻痹、狂怒、百分比生命伤害
- 释放时：棋子闪光 + 按类型不同的粒子（治疗/护盾绿、控制白、增益上箭头、伤害金）

技能名和描述在 `misc_zh.properties` 的 `challenges.autochess.autochessskill.*`（key 用小写类名，如 `name_snake`）。

## 7. 装备

装备**直接用萝卜地牢本体道具**，每只棋子最多 2 件。

| 装备 | 效果 |
|---|---|
| 鼠甲 | 最大生命 +150 |
| 螃蟹护铠 | 受到伤害 −10% |
| 棱镜护铠 | 技能效果 +30% |
| 能量胸甲 | 充能速度 +50% |
| 月华专属比基尼衣 | 攻击伤害 +25% |
| 余晖 | 最大生命 +200 |
| 混灵 | 攻击 +20%，最大生命 +100 |
| 斩舰刀 | 攻击伤害 +40% |

### 获取与使用

- 每回合结束掉落一件（背包上限 9）
- 商店装备格显示本体图标，**拖到棋盘棋子身上**即可装备；单击装到当前选中的棋子
- 棋子条目格式：`类名:星级|装备1,装备2`（随存档保存，合成时保留）

### 合成

- **同名两件**自动合成强化版（id 加 `+`，效果 ×1.7）
- **配方合成**（不同装备）：
  - 鼠甲 + 斩舰刀 → 混灵
  - 鼠甲 + 螃蟹护铠 → 余晖
  - 棱镜护铠 + 能量胸甲 → 月华衣
  - 月华衣 + 余晖 → 混灵

## 8. AI 对手

5 个 AI（老王 / 阿呆 / 包子 / 萝卜头 / 土豆），各自：

- 100 血、1 级起步、有金币和阵容
- **运营**：收入 = 5 + 利息；按 `2 + 回合/2` 追等级，钱多时花 4 金买级；优先补齐差一只的三合一；顺着主力羁绊补人；备战席满了卖低费牌
- **站位**：上场按坦克/战士前排排序
- **装备**：每回合 45% 概率拿一件装备装到自己棋子上

### 配对与结算

每回合所有存活者两两配对：

- 玩家打本轮对手（棋盘上真打）
- 其余 AI 按「阵容战力 + 随机」判定胜负，败者按阶段基础扣血
- 奇数人数时有一个轮空

### 对战大厅（`WndAutochessLobby`）

商店「对战大厅」按钮打开：列出玩家和所有 AI 的血量/等级/本轮对手与胜负，点 AI 看它的阵容。
